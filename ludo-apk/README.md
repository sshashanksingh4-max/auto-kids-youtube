# Ludo Classic APK

A playable local hot-seat Ludo game based on the supplied board references.

## Included
- 2–4 local players
- Four colored tokens per player
- Dice rolling with animated result
- Six required to leave home
- Extra turn on six
- Exact roll required to finish
- Captures on non-safe squares
- Safe starting squares
- Legal-move highlighting and automatic move when only one token is legal
- Restart button
- Portrait Android APK, minSdk 23

The APK is produced by the GitHub Actions workflow in `.github/workflows/build-ludo-apk.yml`.
